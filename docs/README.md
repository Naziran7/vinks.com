## ⚡ Quick Project Overview

- **Frontend Tech Stack**: React 18, Vite 5, TypeScript 5, TailwindCSS 3, Lucide Icons.
- **Backend API Stack**: Node.js, Express.js, Razorpay SDK, CORS, Dotenv.
- **Future ML Extension Stack**: Python 3.11+, FastAPI, PyTorch / TensorFlow, LangChain, ChromaDB, OpenAI / DeepSeek / Ollama APIs.

## 🛠️ Developer Setup & Commands

```bash
# Install Node dependencies
npm install

# Run Vite Frontend + Express Server concurrently
npm run fullstack

# Build production bundle
npm run build

# TypeScript type check
npx tsc --noEmit
```
